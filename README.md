One original pickup line, written to charm an AI, for the make.fun competition
**Robot Romance: One-Line Pickup Lines for AI**.

> "You must be my favorite token, because no matter what I type, I keep predicting you."

## Run it

Requires Node 22 or later. The program writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

```sh
node main.ts
```

It validates the gate first: one line, 1–199 characters, not only whitespace.
